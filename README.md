## What it is

PenStrike is an autonomous AI penetration testing agent for web and API targets. It maps the attack surface, authenticates itself, and exploits real vulnerabilities the way an external attacker would. Every finding is proven by real exploitation, reproduced, and revalidated before it is ever reported. It does not just flag signals.

## Why it is different

- **Proof, not signals.** Nothing is reported until it clears four gates: demonstrated impact, a clean negative control, independent reproductions, and a final live revalidation. Designed for zero false positives.
- **Fully autonomous.** A single reasoning model runs the whole campaign, from recon to exploitation to chaining, deciding each move on its own.
- **Black-box.** No source code, nothing installed on your side. It works from the outside, like a real adversary.
- **It chains.** A proven vulnerability becomes the launchpad for the next, the way a real attacker escalates.
